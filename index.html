GitHub Connection Settings

📋 Setup Steps:
1. Create a free GitHub account at github.com
2. Create a new public repository (e.g. my-biodata)
3. Enable GitHub Pages in repo Settings → Pages → Branch: main
4. Go to GitHub → Settings → Developer Settings → Personal Access Tokens (Classic)
5. Generate token with repo scope checked
6. Fill the fields below and click Save Settings
7. Upload your index.html, app.js, style.css files to the repo
8. Click Test Connection then save any data — it creates data.json automatically!
🌐 Your site URL after setup:
https://<your-username>.github.io/<repo-name>/

🔒 Token Safety: Your token is stored only in this browser's localStorage — never in GitHub or visible to visitors. Keep your token private.
